# Product Requirements Document

## 产品名称
工程 AI 提示词库网页

## 产品定位
一个面向海外路桥工程人员的静态 AI 提示词库网页，用于保存、展示、搜索和复制常用 AI 提示词。

## 目标用户
- 海外道路工程项目管理人员
- 成本控制人员
- 商务合同人员
- 工程技术人员
- 需要中英双语沟通的项目人员

## 核心问题
工程人员日常会频繁写报告、分析合同、回复监理、整理成本资料、学习软件操作。
如果每次都重新组织 AI 提示词，会浪费时间，也不利于经验沉淀。

## 核心功能
1. 首页展示提示词分类。
2. 支持按分类查看提示词。
3. 支持关键词搜索。
4. 每个提示词卡片包含：
   - 标题
   - 适用场景
   - 提示词正文
   - 复制按钮
5. 页面适配电脑和手机。
6. 可部署到 GitHub Pages。

## 提示词分类
- 合同分析
- 成本分析
- 监理英文沟通
- 施工方案
- Civil 3D 学习
- 汇报材料

## 第一版验收标准
1. 打开 index.html 能看到完整页面。
2. 搜索功能可用。
3. 分类按钮可用。
4. 复制按钮可用。
5. 手机端显示正常。
6. 中文不乱码。
7. 不依赖后端服务。
8. 不引入复杂框架。

## 暂不做的功能
- 用户登录
- 数据库
- 在线编辑
- 多人协作
- 复杂权限管理
- 付费系统

## 后续可扩展功能
- 提示词收藏
- 本地导入导出
- Markdown 导出
- 多语言版本
- 项目案例库
- 工程计算小工具
