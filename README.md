# 工程 AI 提示词库网页

## 项目简介

这是一个面向海外路桥工程人员的静态 AI 提示词库网页。项目第一版聚焦“能直接打开使用”：用户可以在浏览器中查看提示词卡片，按关键词搜索，按分类筛选，并一键复制提示词正文。

目标用户包括海外基础设施项目中的工程管理、商务合同、成本控制、监理沟通、技术学习和汇报材料编写人员。

## 第一版功能

- 首页展示项目标题、简介和产品特点。
- 支持按标题、适用场景、提示词正文搜索。
- 支持按以下分类筛选：
  - 合同分析
  - 成本分析
  - 监理英文沟通
  - Civil 3D 学习
  - 汇报材料
  - 工程三维可视化
- 每个提示词以卡片形式展示，包含：
  - 标题
  - 适用场景
  - 提示词正文
  - 复制按钮
- 支持桌面端和手机端自适应显示。
- 使用 UTF-8 编码，中文可正常显示。
- 不依赖后端、数据库或前端框架，可部署到 GitHub Pages。

## 本地使用方式

1. 下载或克隆本仓库。
2. 直接用浏览器打开 `index.html`。
3. 在搜索框输入关键词，例如“索赔”“油耗”“催批复”“横断面”。
4. 点击分类按钮筛选提示词。
5. 点击卡片中的“复制提示词”按钮，将提示词粘贴到 AI 工具中使用。

## 道路工程技术三维可视化｜240讲

在分类区选择“工程三维可视化”，即可复制两阶段提示词。先使用阶段一制作方案卡，收到“方案确认，出总图”后生成独立的00总图；收到“总图确认，继续”后使用阶段二按需生成分图、核查并交付ZIP。总图足够清晰时不强制拆图。完整模板见 [prompts/road-visualization.md](prompts/road-visualization.md)。课程期号及正式标题以已确认的目录为准。

## 静态部署

本项目是纯静态网页，可部署到 GitHub Pages、Netlify、Vercel 静态站点或任意静态文件服务器。部署时只需要保留 HTML、CSS、JavaScript、文档和 prompts 目录即可。

## 使用提示

- 提示词中的【填写】、【粘贴】为占位内容，需要使用者根据项目实际资料补充。
- 项目不会编造真实工程数据、合同条款或标准编号。
- 涉及合同、成本、工期或正式函件时，应由项目负责人或专业人员复核后再对外提交。
